# 用若依学 Spring Boot｜六周学习计划

## 学习目标

学完后，能独立维护一个若依模块。接到需求时，能从页面追到后端和 SQL，判断改动影响，说明方案取舍，完成修改并验证旧功能。这是课程训练架构判断的起点。

每周两课，每课约 90 分钟。第一课在本项目做小实验，第二课对照若依源码并验证。Maven 和配置跟着实际任务学。用「岗位管理」贯穿课程，事务另用课程管理示例。练习在本项目或独立副本进行，若依前后端用于源码对照和本地联调。

## 每周安排

| 周次 | 练习与源码对照 | 验收 |
| --- | --- | --- |
| **第 1 周 · 启动与请求链路** | 启动 `/hello`，从启动类追到 Controller、Service 和配置。随用随学 JDK、Maven、Web Starter、Bean 和构造器注入。对照 `RuoYiApplication`、`SysPostController`。 | 能修改问候语和端口；能从启动日志定位缺失的 Bean；能指出 `message` 属于接口契约。 |
| **第 2 周 · 配置、日志与岗位接口** | 用 `LearnConfig` 练 `@ConfigurationProperties`，用同一个 JAR 验证 YAML、Profile 和命令行覆盖。用 `logback-spring.xml` 练日志级别、控制台输出和滚动归档。阅读岗位列表、详情和新增，再规划修改和删除，对照若依的 `AjaxResult`、`TableDataInfo` 和全局异常处理。 | 能解释哪个配置生效、日志写到哪里。能用请求验证岗位接口、参数校验和错误响应，分清 HTTP 状态与业务 `code`。 |
| **第 3 周 · MyBatis、MySQL 与分页** | 在专用本地 MySQL 中查询岗位，追 Controller、Service、Mapper、XML。用依赖树找 MyBatis、连接池和驱动。对照若依的 Druid 配置、动态 SQL 和分页入口。 | 筛选、翻页结果符合预期；能解释 `rows` 与 `total`；重启后新增数据仍可查询。 |
| **第 4 周 · 若依多模块构建与前后端联调** | 看父子 POM、BOM、传递依赖、`effective-pom` 和 `-pl/-am`。从 Vue 的岗位搜索，经开发代理和后端断点追到 SQL。 | 能解释 Web Starter 从哪个模块引入，能拿实际请求、Controller 参数和 SQL 互相核对。 |
| **第 5 周 · 登录、权限与 Redis** | 追登录、Token 过滤器、Redis 登录状态和 `@PreAuthorize`。用本地账号比较匿名、已登录无权限、已登录有权限三种请求。 | 能判断请求在哪一步被拦下，能区分认证失败与缺少岗位权限。 |
| **第 6 周 · 事务与维护实战** | 对照若依新增用户和关联记录，先用课程标签练新增及编辑回滚，再完成下方岗位筛选变更。 | 能用实际查库结果证明回滚，能用变更说明交代影响、取舍与验证结果。 |

## 结课维护任务

在若依练习副本里实现「岗位列表支持按多个状态筛选」。

1. 从 Vue 页面追到请求参数、Controller、Mapper 和 SQL，检查岗位列表和导出是否共用查询。
2. 写清空筛选、单状态、多状态的预期，验证原有单状态请求、分页、权限以及可能受影响的导出行为。
3. 交付一页变更说明，记录改动范围、为什么把逻辑放在对应层、验证结果和剩余风险。
